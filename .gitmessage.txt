# 사용법: 첫 줄(subject)을 작성하고, 아래 항목은 필요한 것만 남겨 작성하세요.
# 예시(글):   [post] new: Kubernetes ingress 정리 글 발행
# 예시(코드): [code] sidebar: 카테고리 depth 토글 버그 수정

[type] scope: 한 줄 요약

# type
# - post  : 글 작성/수정/발행/SEO
# - code  : 블로그 코드(레이아웃/기능/스타일/설정) 변경
# - chore : 기타 유지보수/정리

# scope (권장)
# post: new | update | seo | typo | series
# code: layout | sidebar | search | theme | config | asset | build

# why
# - 왜 이 커밋이 필요한가?

# what
# - 핵심 변경 1
# - 핵심 변경 2

# note (선택)
# - 배포/호환성/주의사항

# checklist (code 커밋 시 권장)
# - [ ] bundle exec jekyll build 통과
# - [ ] 홈/포스트/카테고리 페이지 확인
# - [ ] 모바일 레이아웃 확인

# refs (선택)
# - 이슈/문서/참고 링크
