GitHub Pages와 Jekyll을 이용해 개인 블로그를 구축했습니다. 이 공간은 학습한 내용, 프로젝트를 진행하면서 얻은 인사이트, 그리고 도전 과제를 기록하는 목적을 가지고 있습니다.

## 왜 GitHub Pages인가?

- **버전 관리**: Markdown으로 작성한 글이 git 히스토리로 남습니다.
- **무료 호스팅**: 별도 서버 없이도 안정적으로 운영할 수 있습니다.
- **개발 친화적인 워크플로**: Pull Request와 Issue를 통해 글과 기능을 개선할 수 있습니다.

## 앞으로의 계획

1. Jekyll 레이아웃과 컴포넌트를 점진적으로 개선합니다.
2. 주간 학습 회고를 정기적으로 업로드합니다.
3. 프로젝트별 정리 자료를 만들어 재방문이 쉽도록 합니다.

## 시작 체크 리스트

```text
[x] 기본 레이아웃과 스타일 구성
[x] 첫 포스트 작성
[ ] 자동 배포 파이프라인 구축
```

이제부터는 꾸준한 기록과 리팩터링이 관건입니다. 앞으로의 여정을 기대해주세요!
