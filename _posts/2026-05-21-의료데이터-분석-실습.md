## 40대 난시 환자와 관련한 통계 분석하기

**1. 엑셀 파일 불러와서 JOIN하기**

```python
patient = pd.read_excel(base_path + "환자ID.xlsx")
diag = pd.read_excel(base_path + "상병데이타.xlsx")

#로직을 짜보자. 주요 칼럼은 환자 ID와 나이, 증상이다.

df = pd.merge(patient[["환자ID", "나이"]],
                     diag[["환자ID", "상병코드"]], 
                     on="환자ID", how="right")
```

**2. 데이터 전처리** <br>
결측값 제거와 중복 제거를 진행했다.

```python
# 40대 난시 환자
target_by_age = df[
```

## 카카오맵 API를 이용한 지도 시각화
나는 예전 프로젝트에서 Kakao Developers API를 사용해본 적이 있어서 수월하게 진행할 수 있었다. [해당 글](https://velog.io/@a_in/Kakao-Map-migration-part.2-get-particular-coordinate-and-address) 참고.
<br>
**1. Kakao geocoder API** <br>
도로명 주소를 위/경도로 변경해주는 API로 kakao.maps.services.Geocoder()를 통해 작동한다.


```javascript
var geocoder = new kakao.maps.services.Geocoder();

var normalized = normalizeAddress(address);

geocoder.addressSearch(normalized, function(result, status) {
  if (status === kakao.maps.services.Status.OK && result[0]) {
    var point = {
      lat: Number(result[0].y),
      lng: Number(result[0].x)
    };

    console.log(point);
  }
});

function normalizeAddress(address) {
  return String(address || "").replace(/\s+/g, " ").trim();
}

```

**2. 환자 주소에 Marker 올리기** <br>


```javascript
var marker = new kakao.maps.Marker({
  position: latlng, // 마커를 찍을 좌표
  image: new kakao.maps.MarkerImage(
    markerSvg(color), // 상병 대분류별 색상 마커
    new kakao.maps.Size(30, 42), // 마커 이미지 크기
    {
      offset: new kakao.maps.Point(15, 42) // 마커 아래 끝이 실제 좌표에 오도록 설정
    }
  ),
  title: patient.patientId + " / " + patient.primaryCode // 호버 시 표시
});
```
